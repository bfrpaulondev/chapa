# CHAPA

PWA de treino do Bruno — barriga chapada, braço grosso.

## Usar no telemóvel

1. Abre `https://bfrpaulondev.github.io/chapa/`
2. iPhone Safari → Partilhar → **Adicionar ao ecrã inicial**
3. Android Chrome → menu → **Instalar aplicação**

Repo: Settings → Pages → Deploy from **main** / root.

Dados ficam no telemóvel (localStorage). Offline após a primeira visita.
